# Spam Email Classifier — Frontend (Angular)

Interface Angular permettant de **saisir le contenu d’un email** et d’obtenir une prédiction **Spam / Non-Spam** via une API Flask.

---

## 🚀 Fonctionnalités
- Champ de saisie d’email (textarea)
- Bouton "Prédire"
- Affichage du résultat (Spam / Non-Spam) 
- Gestion des erreurs (API down, input vide, etc.)

---

## 🧱 Tech Stack
- Angular 
- TypeScript
- HttpClient
- SCSS / CSS

---

## ⚙️ Installation

git clone https://github.com/mohamed-mahmoud-hanenne/Spam-Frontend.git 
cd frontend
npm install

Lancer l’application
ng serve -o
